# 🔐 Password Generator

A simple and modern **Password Generator** built using **HTML5, CSS3, and JavaScript**. It allows users to create random passwords by selecting the password length and required character types.

## ✨ Features

* Adjustable password length from 4–40 characters
* Uppercase letters
* Lowercase letters
* Numbers
* Symbols
* Random password generation
* Password strength indicator
* Copy password to clipboard
* Handles no character selection
* Responsive and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
password-generator/
├── index.html
├── style.css
└── script.js
```

## ⚙️ How It Works

The application creates a character pool based on the selected options. JavaScript uses randomization to select characters from the pool until the required password length is reached.

If no character type is selected, the application displays a message asking the user to select at least one option.

## ▶️ How to Run

1. Create the three project files.
2. Add the respective HTML, CSS, and JavaScript code.
3. Keep all files in the same folder.
4. Open `index.html` in a web browser.
